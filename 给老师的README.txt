🎓 高校教职工人事信息管理系统 - 快速启动指南

====================================
  最简单的运行方法（推荐）
====================================

Windows系统：
1. 双击运行：启动脚本.bat
2. 等待自动安装完成
3. 浏览器访问：http://localhost:5000
4. 登录账号：admin / admin123

Mac/Linux系统：
1. 双击运行：启动脚本.sh
2. 等待自动安装完成  
3. 浏览器访问：http://localhost:5000
4. 登录账号：admin / admin123
